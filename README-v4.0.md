# NADORIO v4.0

Major interface consistency release built on the stable v3.0.4 navigation architecture.

## Highlights
- Unified LINDEX-inspired sizing system across Platform Owner, Club Admin, Manager, Staff, and Member interfaces.
- Standard 42px primary controls and inputs with consistent corner radius, spacing, and icon sizing.
- Standardized panels, cards, data rows, approval controls, module tiles, settings forms, and organization cards.
- Admin/settings forms no longer stretch buttons and inputs into inconsistent proportions.
- Refined desktop and iPhone spacing while preserving the persistent/prefetched v3.0.4 navigation architecture.
- Club-specific branding, module licensing, member enrollment/approval, and existing v3 features remain intact.

## Database
No new Supabase migration is required for v4.0.
Do not rerun prior migrations.
