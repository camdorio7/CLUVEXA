# NADORIO v4.3

Major member, staff, manager and club-admin home experience refresh built on v4.2.

## Highlights
- Larger, more welcoming role-aware home hero for members, staff/managers and club administrators.
- Larger action cards with clearer descriptions and touch targets.
- Member home now emphasizes profile, events, tee times, directory, guest/access tools and club updates.
- Member membership spotlight and upcoming-events presentation redesigned.
- Staff/manager home now emphasizes time clock, daily operations, events, access/check-ins, tee sheet and club updates.
- Club-admin home now has larger operational metrics, management shortcuts and attention items.
- Staff & Team page redesigned with a prominent time clock, polished invitation panel, team cards and recent time entries.
- Responsive sizing improvements for desktop, tablet and iPhone.
- Preserves v3.0.4 persistent navigation/performance architecture and all v4.2 authentication/profile/password functionality.

## Database
No new Supabase migration is required for v4.3.
