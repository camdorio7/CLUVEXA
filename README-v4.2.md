# NADORIO v4.2
Major member-experience and operational-design release built on v4.1.3.

Highlights:
- New public NADORIO home page.
- Universal sign-in retained with automatic organization/role routing.
- Forgot-password + secure reset-password flow through Supabase Auth/Resend SMTP.
- Rebuilt member home with personalized membership identity, quick actions and upcoming events.
- New My Profile page with membership details and editable phone number.
- New Member Directory.
- Member navigation now includes Profile and Directory.
- Fixed malformed Platform Owner module licensing switches by separating their CSS from club settings controls.
- Preserves persistent fast workspace navigation and v4.1 membership application/approval system.

No database migration is required for v4.2.
